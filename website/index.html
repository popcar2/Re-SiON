Re-SiON

SongsPlaygroundConvertDocs

Re-SiON is a tiny software synthesizer library (~40kb WASM gzip'd) that plays plaintext Music Macro Language files, providing fantastic quality music and sound effects at negligable file sizes.

This is a Rust re-implementation of the SiON library, originally created by keim for Adobe Flash many moons ago. Re-SiON brings it back for the web and desktop platforms via a Rust crate and shared library (.dll/.so)

This project also comes with a playground to write and test MML, and a converter that converts from other tracker formats (e.g. MOD, XM, IT) and retro video game formats (e.g. NSF, VGZ, SPC) to readable MML.

But why use Re-SiON?

  • It's a tiny, no-dependency library. Perfect for use in small web apps and game engines.
  • MML files are tiny, an entire song fitting in only a few kilobytes!
  • MML files are plaintext, making them easy to edit without an external program.
  • The converter translates many different file formats to MML, allowing you to play all your chiptune in one unified player without juggling file formats.
